# No backend: bring-your-own API key, Notes shared as portable data

v1 is a personal tool with no server. The extension calls the Anthropic API directly with the user's own key, and Notes for a Video live locally. Sharing means exporting Notes and having someone import them. We deliberately rejected a shared online library, where anyone opening a Video sees published Notes, because it requires accounts, hosting and moderation, none of which a personal tool justifies.
